# /reachout

Draft personalized outreach messages in the candidate's voice. This is the human
side of the search — LinkedIn networking, warm intros, and follow-ups.

Read `08-outreach.md` for channel rules and templates, `01`/`02` for the
candidate, and `03-writing-style.md` for tone (no em-dashes, no clichés).

Input `$ARGUMENTS`: a message type plus context. Types:

- `connection` — LinkedIn connection note (**≤300 characters**).
- `recruiter` — reply to / cold message a recruiter.
- `hiring-manager` — direct note to the hiring manager.
- `referral` — ask a contact for a referral / warm intro.
- `followup` — follow up after applying or after no response.
- `thanks` — thank-you after an interview.

Steps:

1. Identify type and gather context (company, role, person, any prior thread).
   Research the company/person with WebSearch when useful.
2. Draft per `08-outreach.md` for that channel, respecting length limits.
3. Ground every claim in the real profile — never invent shared connections,
   mutual interests, or experience.
4. Offer 2 variants (shorter / warmer) when helpful, and note the character
   count for length-limited channels.

Never send anything — only draft. The user sends it themselves.
