# Tesla Megapod Program — Executive Package

*Strategy, targets, contacts, scripts, and paper for Tesla to approach Bitcoin miners and neoclouds as an offtaker: Tesla deploys Megapods (Tesla compute plus Megapack 3 storage) at sites that already have power, and pays the host a fixed fee per reserved megawatt.*

Prepared November 8, 2026. Market facts, deal values, and executive names are from public filings, earnings materials, press releases, and trade press dated 2025–2026; every file flags figures that rest on a single secondary source as UNVERIFIED. Nothing here is Tesla confidential information; the Megapod block specification and fee bands are program assumptions for Tesla to confirm.

## Rules this package follows

- **No guessed contact details.** A name appears only with a dated source. An email appears only if it was printed on a page we read, with that page's URL. One email qualifies (an investor-relations contact at Bitdeer).
- **Gross versus IT megawatts are labeled.** Mining capacity is gross; HPC leases are critical IT; the conversion is about 1.33.
- **Related-party firewall.** SpaceX and xAI appear only as public Megapack reference customers. The program does not touch their capacity.
- **Unverified means unverified.** Where one secondary source is all we have, the text says so.

## How this was built

Five parallel research passes (Tesla's position; two cohorts of miners; neoclouds and power-first developers; deal comps and unit economics) using web search and indexed filings, then synthesis into the strategy, economics, and target documents. Direct fetches of company and SEC pages were blocked by the session's network policy, so filings were read through search snippets and an indexed filings service; primary-document links are given so each figure can be checked against the original.
